Syarat & Ketentuan

Ketentuan penggunaan layanan Amat Store.

1. Ketentuan Umum

• Seluruh transaksi yang telah diproses dan dinyatakan berhasil oleh sistem bersifat final dan tidak dapat dibatalkan atau diubah secara sepihak oleh pembeli.

• Harga layanan top-up (seperti Diamond, Token, dan Membership) dapat berubah sewaktu-waktu mengikuti kebijakan server pusat tanpa pemberitahuan sebelumnya.

2. Kesalahan Input Data (User ID)

• Pembeli diwajibkan untuk memeriksa kembali kelengkapan dan kebenaran data akun tujuan (User ID, Zone ID, atau Server) sebelum melanjutkan ke pembayaran.

• Segala bentuk kerugian yang diakibatkan oleh kesalahan input (typo/salah ketik ID) sepenuhnya menjadi tanggung jawab pembeli. Produk yang sudah berhasil terkirim ke ID yang salah tidak dapat ditarik kembali, dibatalkan, maupun di-refund.

3. Proses Pembayaran & Transaksi

• Pembayaran hanya dianggap sah jika dilakukan melalui tautan atau metode pembayaran resmi (Payment Gateway) yang muncul secara otomatis di website Amat Store. Jangan pernah melakukan transfer ke rekening pribadi di luar sistem.

• Transaksi top-up akan diproses secara otomatis oleh sistem segera setelah status pembayaran terkonfirmasi lunas.

• Pada kondisi tertentu, seperti gangguan dari server game pusat (maintenance) atau kepadatan API, pesanan mungkin mengalami penundaan (pending). Mohon menunggu atau hubungi layanan pelanggan jika pesanan belum masuk.

4. Kebijakan Pengembalian Dana (Refund)

• Komplain atau pelaporan kendala transaksi dapat dilakukan maksimal 1x24 jam sejak pesanan dibuat.

• Pengembalian dana (refund) 100% hanya berlaku apabila saldo/dana sudah terpotong namun transaksi berstatus "Gagal" akibat gangguan pada sistem Amat Store atau server pusat.

• Refund tidak berlaku untuk kasus kesalahan input User ID oleh pembeli, atau jika riwayat server pusat mencatat bahwa produk sudah sukses terkirim ke akaun yang terdaftar pada pesanan.

5. Layanan Pelanggan

• Seluruh pertanyaan dan keluhan transaksi dilayani melalui kontak WhatsApp resmi Pusat Bantuan Amat Store.

• Saat menghubungi layanan pelanggan, pembeli wajib menyertakan Nomor Pesanan (Order ID) dan bukti pembayaran yang valid untuk mempercepat proses pengecekan.
